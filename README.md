 # Footprinting and Reconnaissance Lab

A hands-on cybersecurity lab focused on information gathering and reconnaissance using Kali Linux.

## Objective

The objective of this lab was to perform reconnaissance on a target domain and document the information gathered during the assessment.

## Tools Used

- Kali Linux
- DNSRecon
- WHOIS
- NSLookup
- cURL
- WhatWeb
- Wafw00f
- GitHub

## Activities Performed

### DNS Reconnaissance
Used DNSRecon to perform DNS enumeration and identify available DNS records.

### WHOIS Lookup
Gathered publicly available domain registration information using WHOIS.

### NSLookup
Performed DNS lookups to obtain domain and DNS information.

### HTTP Header Analysis
Used cURL to inspect HTTP response headers.

### Web Technology Identification
Used WhatWeb to identify technologies used by the target website.

### WAF Detection
Used Wafw00f to check for the presence of a Web Application Firewall.
